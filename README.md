# 展会名片整理助手支持网站

公开静态技术支持与隐私政策，仅 HTML、CSS 和原创图标，无脚本、表单或统计插件。应用源码独立保存在私有仓库，此处不放联系人、名片、备份、账号或签名信息。

本地预览：`python3 -m http.server 8768 --bind 127.0.0.1`。

部署使用 GitHub Pages，唯一 `main` 分支的根目录；访问入口：<https://tillywong153111.github.io/exhibition-card-support/>。隐私政策：`privacy.html`。使用条款链接到标准应用许可协议，支持问题通过本公开仓库的 Issues 提交。提交前检查 HTML 标签、内部文件链接、移动端布局及命名限制；部署后确认入口和隐私页返回成功。
